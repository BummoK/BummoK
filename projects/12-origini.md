# 🌿 ORIGIN I · 브랜드 웹사이트

**딥그린·골드·타이포그래피를 중심으로 브랜드 콘텐츠를 구성한 개인 웹 프로젝트입니다.**

![ORIGIN I editorial prototype](../assets/screenshots/origini-editorial.jpg)

*브랜드 소개와 콘텐츠를 구성한 전체 페이지 시안입니다.*

## 1. 구현 경험

- 브랜드 소개와 제품·사업 콘텐츠를 연결하는 페이지 구성
- 반응형 레이아웃, 가로 카드 탐색과 스크롤 등장 효과
- 한국어·영어 콘텐츠 전환
- 문의 폼 UI와 입력 후 피드백

## 2. 페이지 구성과 남은 작업

시작 페이지는 **Coming Soon**으로 구성했고, 위의 전체 브랜드 페이지는 별도 HTML 시안으로 만들었습니다. 문의 폼의 메시지 전송과 외부 스토어 연결은 아직 구현 전입니다.
