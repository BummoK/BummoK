# 같은 알고리즘이 실행 환경마다 같은 결과를 내는지 확인하기

[포트폴리오](../README.md) · [오류 분석](02-evaluation.md)

Python에서 확인한 알고리즘을 제품에 적용하려면 모델 파일뿐 아니라 입력 처리와 판정 결과도 맞아야 합니다. **5,912개 저장 시행**을 재생하며 Python, 네이티브 코드와 Windows DLL의 결과를 비교했습니다.

## 1. 비교한 것

1. 학습 체크포인트와 추론용 모델을 구별하고 파일 해시로 버전을 확인했습니다.
2. 배포 모델과 펌웨어 소스에 들어간 모델 데이터를 대조했습니다.
3. 같은 파생 입력을 사용하는 Python·네이티브 재생을 비교했습니다.
4. 원본 CSV를 직접 처리하는 DLL과 파생 입력 재생의 차이를 확인했습니다.

## 3. 시점이 달랐던 한 건

판정은 같았지만 첫 검출 시점이 한 프레임 다른 사례를 발견했습니다. 파생 데이터에 기록된 모델 점수의 반올림 경계와 맞물린 현상으로 조사됐습니다. 결과가 같다는 것과 검출 시점까지 같다는 것을 나눠 확인할 필요가 있었습니다.

실제 보드의 처리시간과 최종 알람은 별도 장치 시험에서 확인해야 합니다. 이 비교는 저장된 동일 입력을 여러 구현에서 재생했을 때의 차이를 찾는 데 초점을 맞췄습니다.
