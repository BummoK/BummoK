# IMU 기반 낙상 감지 AI 개발

[포트폴리오](../README.md) · [평가 사례](02-evaluation.md)

> **English summary:** Developed and evaluated IMU-based fall-detection algorithms, combining deep learning with physical and temporal movement characteristics. The work connected preprocessing, staged training and trial-level error analysis.

**핵심 기여** · 센서 전처리와 모델 학습을 시행 단위 평가에 연결하고, 오탐·미탐 분석을 알고리즘 개선에 반영했습니다.

## 1. 프로젝트와 담당 업무

- **목표:** 웨어러블 IMU 신호에서 낙상과 일상동작을 구분하고, 검출 시점까지 고려하는 알고리즘 개발.
- **담당:** 알고리즘 개발, 성능 평가, 오류 분석 및 개선 전반.
- **기술 환경:** Python, TensorFlow/Keras, TensorFlow Lite, 센서 시계열 처리.

## 2. 해결해야 했던 문제

일상동작에서도 낙상과 비슷한 센서 신호가 나타날 수 있습니다. 낙상 검출 여부뿐 아니라 정상 동작의 오경보와 검출 시점을 함께 평가해야 했습니다. 모델 학습에 사용하는 짧은 입력 창과 실제 판정 대상인 한 번의 동작 시행도 서로 다른 평가 단위였습니다.

## 3. 개발 접근

1. 센서 신호의 채널·단위·시간축과 전처리 조건을 맞춰 모델 입력을 구성했습니다.
2. 공개 낙상 데이터 기반 학습과 추가 일상동작 데이터를 사용하는 전이학습을 구분해 다뤘습니다.
3. 모델 점수를 실제 판정에 연결할 때 **AI 추정과 물리적·시계열적 움직임 특성을 종합한 판정**을 적용했습니다.
4. 오탐·미탐 사례를 원본 시행과 신호 구간으로 돌아가 분석하고, 변경 사항의 회귀 영향을 확인했습니다.

## 4. 남긴 결과

- 모델 학습 설정, 체크포인트, 추론용 모델을 구분해 관리하는 개발 흐름.
- 낙상 검출, 정상 동작의 오경보, 검출 선행시간을 함께 살펴보는 평가 방식.
- 특정 실패 동작을 분석하고 기존 동작에 대한 영향을 비교하는 개선 과정.

이 사례의 핵심은 모델 학습을 실제 판정 문제와 연결한 경험입니다. 검증 창의 정확도와 원본 시행 단위 결과를 분리해 해석했으며, 두 학습 단계의 검증 데이터 구성이 다른 경우 정확도 차이를 개선 폭으로 계산하지 않았습니다.

## 5. 검증 범위

학습·재생 평가와 제품 적용용 알고리즘 검증을 다룹니다. 새 착용자나 현장의 독립 시험, 실제 기기의 최종 알람 성능은 별도의 검증 대상입니다.
