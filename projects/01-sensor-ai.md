# 웨어러블 낙상 감지 알고리즘 개발

[포트폴리오](../README.md) · [오류 분석](02-evaluation.md) · [실행 결과 비교](03-deployment-verification.md)

웨어러블 에어백에서 어려운 문제는 낙상을 놓치지 않으면서 일상생활의 큰 움직임에 불필요하게 반응하지 않는 것입니다. 세이프웨어에서 센서 전처리, 모델 학습, 성능 평가와 개선을 맡고 있습니다.

## 1. 센서 신호를 모델 입력으로

IMU의 채널·단위·시간축을 확인하고 전처리 조건을 맞췄습니다. 공개 낙상 데이터를 이용한 학습과 추가 일상동작 데이터를 이용한 전이학습을 진행하며, 움직임의 종류에 따라 결과가 어떻게 달라지는지 분석했습니다.

## 2. 모델 출력을 실제 판정으로

모델의 점수만으로 판단하기 어려운 움직임을 다루기 위해 **AI 추정과 물리적·시계열적 움직임 특성을 종합한 판정**을 적용했습니다. 낙상을 검출했는지뿐 아니라 언제 검출했는지, 비슷한 일상동작에서 오경보가 발생하는지도 함께 살폈습니다.

## 3. 실패 동작으로 돌아가 개선

1. 미검출·오경보 파일에서 센서 신호와 모델 출력을 확인합니다.
2. 어떤 움직임과 구간에서 문제가 생겼는지 찾습니다.
3. 모델 또는 판정을 수정하고 같은 파일로 다시 평가합니다.
4. 기존에 잘 검출하던 동작과 정상 동작에도 영향이 없는지 확인합니다.

짧은 학습 창의 분류 정확도와 한 번의 전체 동작을 판정한 결과는 따로 봅니다. 저장 데이터 재생으로 원인을 좁힌 뒤 실제 장치에서 확인할 항목을 정리하는 방식으로 작업합니다.

**기술:** Python · TensorFlow/Keras · TensorFlow Lite · IMU 시계열 · NumPy · pandas
