# ✨ GLOW PICK · 화장품 탐색과 리뷰

**상품 탐색부터 상세·리뷰·사용자 흐름까지 연결한 개인 풀스택 프로젝트입니다.**

> English: A personal React/Express/MongoDB prototype for cosmetic discovery, filtering and reviews.

![GLOW PICK demo](../assets/screenshots/glow-pick.jpg)

*합성 데모 상품 3개로 촬영한 로컬 화면입니다. 가격·평점·리뷰 수는 실제 서비스 실적이 아닙니다.*

## 1. 구현 범위

| 사용자 경험 | 구현 |
|---|---|
| 원하는 상품 찾기 | 이름·브랜드·태그 검색, 카테고리 필터, 정렬 |
| 상품 살펴보기 | 상세 화면, 리뷰와 평점 표시 |
| 사용자 흐름 | 회원가입·로그인 UI와 인증 API |
| 데이터 관리 | Express 상품·리뷰 API와 MongoDB 모델 |

React 라우팅, API 호출, 서버 라우트와 데이터 모델을 하나의 프로젝트로 연결했습니다. 아이콘과 알림 메시지를 사용해 화면 피드백을 구성했습니다.

## 2. 현재 확인 범위

프런트엔드 빌드와 합성 데이터 화면을 확인했습니다. 실제 서비스·데이터베이스에는 쓰기를 수행하지 않았습니다. API 주소 통일과 인증·권한 처리 보완은 후속 작업이며, 완성된 상용 서비스의 운영 성과로 소개하지 않습니다.

**기술:** React 19 · Vite · React Router · Express 5 · MongoDB · Mongoose · JavaScript
